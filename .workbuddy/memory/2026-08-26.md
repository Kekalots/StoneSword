# 2026-08-26 石中剑 Unity 项目 - 背包系统 Bug 修复

## 问题
用户 2D 游戏（Tuanjie/团结引擎编辑器）背包系统两个症状：
1. 游戏开始后背包面板自动关闭，按 I 键无法打开
2. 运行时手动勾选 InventoryPanel，显示 20 个空格子（无图标）

## 根本原因
**InventoryUI 脚本挂在 InventoryPanel 自身 + Start() 里 panelRoot.SetActive(false) = 自杀死锁**
- SetActive(false) 禁用面板时，挂在面板上的 InventoryUI 组件也一并禁用
- Update() 不再运行 → 按 I 永远无反应
- 20 个空格子是正常的：InventoryItemManager.Start() 调用 RefreshAllUi()（普通方法调用不受禁用影响）正常实例化了格子；itemList 为空所以 SetEmpty() 隐藏了图标

## 修复（已完成）
改写 Assets/Inventory/Scripts/InventoryUI.cs：
1. 显隐改用 CanvasGroup（alpha/interactable/blocksRaycasts），面板物体保持激活，脚本持续运行；Awake 里自动补 CanvasGroup 组件
2. RefreshAllUi 改为懒生成：首次调用 SpawnAllSlots() 生成 20 格，之后只刷数据不销毁重建
3. 加了 playerInteract / InventoryItemManager.Instance 的空引用防护

## 关键项目事实
- 项目用 Tuanjie Editor（团结引擎，Unity 2022.3.62t11），meta 文件 GUID 为 base64 样式字符串，场景 YAML 引用正常工作
- InventoryItemManager 挂在 PlayerBody 上，inventoryUI→InventoryPanel、itemTipUI→TipUIPanel 引用完好
- InventoryUI 字段名被用户改过（ItemContent→content，新增 slotPrefab/interactTipText/playerInteract），Inspector 序列化引用按字段名匹配，改名导致旧引用丢失，需重新拖
- ItemButton.prefab 结构：根物体 Image（背景）+ 子物体 Image（iconImage，代码动态填 sprite）
- 用户改完代码后需在 Inspector 重新拖：slotPrefab、content、interactTipText、playerInteract（panelRoot 引用应仍在）
