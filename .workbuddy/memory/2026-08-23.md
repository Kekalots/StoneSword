# 2026-08-23 工作日志

## Unity 石中剑项目 — 史莱姆动画锁死移动修复

**问题**：史莱姆加动画后停在原地不动，删掉动画就正常移动。

**根因**：
1. `SlimeAttack.anim` 录制了 `Transform.position`（m_LocalPosition x/y/z）的绝对世界坐标关键帧（-9.21, -1.17 等），Animator 直接覆写 position，与 Rigidbody2D.velocity 冲突
2. Animator Controller 两个 State 都开了 Write Defaults（m_WriteDefaultValues: 1），Animator 持有 position 属性即使处于 SlimeMove 状态也不释放
3. `SlimeMove.anim` 的 Loop Time 未开启（m_LoopTime: 0）

**修复**：
- `SlimeAttack.anim`：清空 m_PositionCurves，m_HasGenericRootTransform 设为 0，删除所有 position 编辑器曲线，保留 Animation Event（AttackAnimationFinished @ 0.333s）
- `SlimeMove.anim`：m_LoopTime 从 0 改为 1
- `Slime.controller`：两个 State 的 m_WriteDefaultValues 从 1 改为 0

**注意**：Player 的 SwingSword.anim 也有 m_PositionCurves（非空），PlayerBody.controller 的 Write Defaults 也全是 1。如果玩家出现类似问题需要同样处理。
